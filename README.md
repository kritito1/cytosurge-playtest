# CYTOSURGE Web Playtest

Public, no-login Web build of CYTOSURGE v1.1.0 for landscape mobile playtesting.

Current build source: `codex/combat-readability` at `d4984fcb9cefb0f2e472ee27c74f1c5ee21c37c7`.

This build adds a three-map campaign with sequential unlocks, KRAFT ARCHIVE and
VELLUM THEATRE paper-world identities, STAPLE WARDEN and VELLUM DIRECTOR
Bosses, five distinct hit tiers, four death-cut marks, and a torn-paper player
damage overlay. It retains orbit knockback, enemy readability, and iOS Safari
playback-session audio improvements.

- Open the GitHub Pages URL in Safari or Chrome.
- Rotate the phone to landscape.
- Tap once to unlock browser audio.
- Save data is local to this browser and origin; no account or cloud sync is used.

This repository contains compiled Godot Web export artifacts only. The game source is not published here.
